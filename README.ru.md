# MONTECH MKey PRO 75 — открытая прошивка QMK

[English](README.md) · [Скачать прошивку](https://github.com/ruslan200065/-MONTECH_Mkey_Pro_75/releases)

Прошивка сообщества для **MONTECH MKey PRO 75 ANSI**. За основу взята беспроводная ветка QMK от Keychron и код Lemokey P1 Pro. В репозитории есть исходники порта, раскладки и изменения общего беспроводного кода. В релизе лежит готовый образ для WB32 и полный комплект исходников для сборки.

| Возможность | USB | 2.4 ГГц | Bluetooth |
|---|---|---|---|
| Набор текста, энкодер, встроенная подсветка, Win/Mac | Да | Да | Да |
| Настройка через VIA | Да | Экспериментальный JSON | — |
| Управление через OpenRGB | Да | Обмен через донгл не подтверждён | — |

### Что сделано

- Восстановлены порядок столбцов матрицы MONTECH, 12-фазный режим LED-драйвера и разводка подсветки вокруг ручки. [Разбор железа](docs/hardware-proof.md)
- Исправлены положения BT и 2.4G на физическом переключателе. Win/Mac выбирает свою пару слоёв. В Mac верхний ряд управляет медиа и светом, а с Fn отправляет F-клавиши.
- Ручка переключается между громкостью, зумом и эффектами. Кольцо показывает выбранный режим. Режим и состояние подсветки кольца сохраняются в EEPROM. Зум отправляет Ctrl в Win и Command в Mac. Fn + вращение меняет яркость.
- Подсветка включает 81 LED клавиш и 7 LED кольца. Ещё два RGB-канала драйвера обслуживают шесть физических делений АКБ. Шкала заполняется снизу вверх и ждёт первого замера. При зарядке заполненные деления горят постоянно, остальные мигают. Fn+B показывает заряд на цифровом ряду, Fn+Esc гасит всю подсветку вместе со шкалой.
- При работе от батареи в BT и 2.4G яркость ограничена до 128 из 255 по ШИМ. Через минуту бездействия подсветка гаснет, затем клавиатура уходит в режим STOP с пробуждением по клавише. При потере связи подсветка может погаснуть раньше.
- Добавлен VialRGB по USB с Direct-режимом, встроенными эффектами, ответом на каждый пакет и отдельной колонкой кольца в карте LED. VIA управляет цветом отдельных клавиш. Эти цвета хранятся до выключения питания. В комплекте есть утилита подсветки по цветам экрана и инструменты диагностики.

### Как прошить

1. Сохрани свою раскладку VIA и скачай из релиза файл **ANSI** `.bin`.
2. Открой файл в [QMK Toolbox](https://qmk.fm/toolbox). На клавиатуре выбери режим **USB**.
3. Отключи кабель, зажми **Esc** и подключи кабель обратно, чтобы войти в WB32 DFU. Отпусти Esc, запусти прошивку и дождись завершения. Затем переподключи клавиатуру.
4. Если VIA сохранила старые слои и раскладка Mac не появилась, после резервной копии нажми **Fn+Del в положении Win**. Комбинация сбрасывает пользовательские настройки и загружает раскладки прошивки.

Заводской образ для отката и официальная инструкция находятся в разделе Downloads на [странице MONTECH](https://www.montechpc.com/mkey-pro). Для этой раскладки нужен **QMK BIN_ANSI**.

### VIA и OpenRGB

- **VIA по USB.** В [VIA](https://usevia.app) включи вкладку Design, загрузи [проводной JSON V3](via/mkey_pro_75_ansi_usb.json) как draft и авторизуй клавиатуру на вкладке Configure. Слои 0/1 — Win и его Fn, 2/3 — Mac и его Fn.
- **OpenRGB по USB.** В сборке с детектором **QMK VialRGB Devices** добавь VID `362D` и PID `1700`. Переподключи клавиатуру или повтори поиск устройств. Для передачи цветов из программы выбери **Direct**. Кольцо отображается отдельной колонкой. [Исходники OpenRGB](https://gitlab.com/CalcProgrammer1/OpenRGB)
- **2.4 ГГц.** [Экспериментальный JSON](via/mkey_pro_75_ansi_24g_experimental.json) использует реальный VID/PID донгла `362D:D101`. На проверенном экземпляре донгл печатает, но не отвечает на запросы VIA и VialRGB. Для работы VIA и OpenRGB по воздуху нужен подтверждённый канал передачи команд. [Результаты проверки](docs/receiver.md)

### Как собрать

На Windows с Git и запущенным Docker Desktop в режиме Linux-контейнеров:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/setup.ps1
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
```

Скрипты загружают фиксированную ревизию Keychron QMK и её зависимости, накладывают порт и собирают `firmware/montech_mkey_pro_75_via.bin`. QMK встраивает дату сборки, поэтому локальный файл может отличаться побайтово.

Утилиты USB устанавливаются через `python -m pip install hidapi pillow`. `tools/mkey_light.py --selftest` проверяет VIA и VialRGB, `tools/mkey_ambient.py --mode screen` включает подсветку по экрану, а `tools/batmap.py` проверяет позиции делений батареи. Перед диагностикой закрой OpenRGB.
